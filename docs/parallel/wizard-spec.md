# 首次使用向导 · 交互与数据契约（B3.0 · 2026-10-20）

> 目的：新装用户第一次打开 Zotero 时，用**三步**把「能聊、能翻、能看」跑通，而不是让人
> 在 18 组设置里自己找。本文件只定契约，不写代码；B3.1 / B3.2 / B3.3 按它实现。

## 1. 触发与生命周期

| 场景 | 行为 |
|---|---|
| 首次安装 / 从 < 0.66 升级后首次启动 | 主窗口就绪后 **延迟 3s** 弹向导（避免和 Zotero 自己的欢迎页抢焦点） |
| 走完三步 | 写 `wizardDone = "done"` + `wizardDoneAt = <ISO>`，此后不再自动弹 |
| 点「稍后再说」/ 直接关窗 | 写 `wizardDone = "skipped"`，**不再自动弹**；菜单仍可手动重开 |
| 菜单「工具 → Papilot → 首次使用向导」 | 任何时候可重开，**不清空**已填内容，显示当前实际值 |
| 设置面板工具条「首次使用向导」 | 同上（0.68.0 增：设置里就能找到，不必先想起菜单路径） |
| 重置（设置面板「重新运行向导」） | 清 `wizardDone`，下次启动再弹 |

> 幂等：重复打开不重置任何配置；向导只写「用户在这个界面上明确选择过」的项。

## 2. 三步流程

### 步骤 1 · 账号（可跳过）
- 复用现有登录接口（`Zotero.Papilot.account.login`），不新写鉴权。
- 若已登录：显示邮箱 + 会员档位，直接可「下一步」。
- 未登录：邮箱 + 密码 + 「登录」；下面一行小字「没有账号？可以先跳过，之后在设置里登录」。
- 跳过不影响后面两步（官方通道会退化为不可用，第 2 步会提示）。

### 步骤 2 · AI 通道（可跳过）
- 默认选中「官方通道（登录即用）」；未登录时该项灰显并说明原因。
- 备选「自建 / 其他 OpenAI 兼容接口」：baseUrl + API Key + 「测试连接」（复用 `channels.detect`）。
- 测试失败**不阻断**：显示原因 + 「仍然保存」+ 「下一步」。
- 写入：`channelsConfig`（新通道 id 固定 `wizard-<ts>`）、`activeChannel`。

### 步骤 3 · 翻译引擎（可跳过）
- 两个大按钮：「AI 大模型（推荐，需要第 2 步可用）」「免费引擎（Google / 必应，无需配置）」。
- 选 AI 但第 2 步没配 → 自动回落到「免费引擎」并提示一句。
- 写入：`translate.active`、`translate.fallback = "google, bing"`（仅当当前为空）。

### 完成页
- 一句话总结三步结果（✓/—），两个按钮：「打开设置」「开始使用」。
- 不引导付费、不展示营销。

## 3. 写入白名单（只允许动这些）

```
wizardDone              "done" | "skipped"        （生命周期）
wizardDoneAt            ISO 时间
channelsConfig         仅**追加**新通道，不改已有通道
activeChannel          仅当为空或指向被删通道时才改
translate.active       仅当为空时才改
translate.fallback     仅当为空时才改
```

**禁止**：不改 `aiSystemPrompt` / `researcherProfile` / 任何密钥以外的既有非空值；不写 `easyScholarKey` 等第三方密钥。

### 步骤 3 的可选搭子：设置面板「⚡ 推荐配置」
向导负责「从零配好」，工具栏的「推荐配置」负责**日常补齐**：只列出与推荐值不一致的项、
确认后才改，白名单仅 6 个体验开关（划词浮窗 / 标题进度 / 引用可点 / 相关文献 / 复用库内标签 / 更新提示），
不碰密钥、计费、账号与主题。用户全已是推荐值时只回一句「已是最佳配置」。

## 4. 异常与降级

| 异常 | 处理 |
|---|---|
| 没有网络 | 每步可跳过；「测试连接」失败只提示，不卡流程 |
| 登录超时 / 401 | 提示 + 「重试」/「跳过」，不关闭向导 |
| 写入 pref 失败 | 该步标红但允许继续；完成页列出未写入项 |
| 主窗口未就绪 | 不弹（等 `uiReadyPromise`），不阻塞启动 |
| 用户连点 / 重复触发 | 单例：已存在 `papilot:wizard` 窗口则聚焦，不新开 |

## 5. 交互与可访问性

- 键盘：Tab 顺序 = 主操作在最后；`Esc` 等同「稍后再说」；`Enter` 触发该步主按钮。
- 焦点：进入每步时聚焦第一个可操作元素；步骤切换后焦点回到标题。
- 宽度 ≤ 560px：单列；步骤条折叠为「1/3 · 账号」。
- 只用 `ui-kit` 的 `.pp-btn/.pp-input/.pp-select/.pp-label/.pp-hint/.pp-empty`，不新增 inline 样式。

## 6. 验收

- `test/wizard.test.js`：三步推进 / 跳过写 `skipped` / 重开不重置 / 写入白名单外的 pref 一律不改 /
  无网络时三步均可走完 / 单例（第二次调用复用窗口）。
- 人工：新 profile 首启弹一次；「稍后」后不再弹；菜单可重开；暗色下无白块。
