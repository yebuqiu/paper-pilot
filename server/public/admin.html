价格与计费周期

价格条目 = 会员等级 × 计费周期 × 生效时段，全部由本表驱动，改完立即生效（无需重启服务）。 生效时段留空即「立即生效 / 长期有效」；填了未来的起始时间就是定时生效，到点自动切换，客户端会先看到「即将生效」预告。

优惠券 / 折扣码

与激活码的分工：激活码是「直接发会员」（免费、不走订单）；优惠券只打折，用户仍走完整 「下单 → 收款 → 核销」流程。想免费送用激活码，想让人少掏点钱用优惠券。 折后金额仍会再加 1~99 分的专属对账尾数，自动对账不受影响。

名额在下单时占用、订单取消或超时自动释放、核销才真正消耗 —— 所以用户反复下单/取消不会把限量券耗光。折后至少留 ¥1（100% 减免请发激活码）。 已被占用的券不能删除，但可以停用（停用只影响新订单，不影响已经下过的单）。
